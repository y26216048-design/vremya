# Instagram на ноутбуке

Расширение для Chrome, Edge, Brave и других браузеров Chromium блокирует открытие `instagram.com`, `instagr.am` и их поддоменов, в том числе во фреймах. YouTube не блокируется. Данные не собираются, фоновых скриптов нет.

## Установка в Chrome (Windows)

1. Скачайте ZIP этой ветки репозитория и распакуйте его.
2. Откройте `chrome://extensions`.
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку `desktop/chrome-extension`.
5. Откройте `https://www.instagram.com/`: Chrome должен показать, что страница заблокирована расширением. Проверьте также уже открытые вкладки, обновив их.
6. В сведениях расширения включите «Разрешить использование в режиме инкогнито», если используете этот режим.

В Edge используйте `edge://extensions`. Для каждого браузера и профиля расширение устанавливается отдельно. Оно работает, пока включено; его можно отключить или удалить. На остальные приложения ноутбука и браузеры телефона оно не распространяется.

## Телефон: проверка InstaPro3

Android-правила включают `com.instapro.android`, `com.instapro2.android`, `com.instapro3.android`. У разных сборок модификации пакет может отличаться. На Windows с подключённым телефоном и разрешённой USB-отладкой выполните:

```powershell
adb devices
adb shell pm list packages | findstr /i insta
```

Если ADB лежит в текущей папке PowerShell, вместо `adb` используйте `./adb.exe`. Нужен фактический пакет установленной версии: имя и иконка на рабочем столе его не подтверждают.

Для обновления Android-приложения нужен исходный ключ подписи. Не удаляйте установленное «Время» ради установки APK с другой подписью: это сбросит его настройки и код. Блокировка сайтов на телефоне уже предусмотрена для поддерживаемых браузеров и требует включённой службы «Время».
