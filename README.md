# Время

Локальный блокировщик отвлекающих приложений для Android 9 и новее. Instagram и официальный YouTube закрываются при входе, без сообщений. ReVanced остаётся доступным.

## Первый запуск

1. Установите APK и откройте «Время».
2. Прочитайте предупреждение. Попросите доверенного человека задать код и повторить его. Код нужно сохранить у этого человека: смены и восстановления кода в приложении нет.
3. Включите «Время — защита приложений» в специальных возможностях Android. Если система требует, сначала откройте сведения о приложении → ⋮ → «Разрешить ограниченные настройки».
4. Вернитесь в «Время» и нажмите «Завершить настройку». После этого вход в настройки блокировщика будет требовать код.

Код задаётся один раз для этой установки. Очистка данных или удаление приложения может сбросить настройку. После обновления уже настроенного приложения прежний код сохраняется; повторная регистрация не требуется. В APK нет чужого или общего пароля.

## Возможности

- Закрытие Instagram, Instagram Lite и официального YouTube при открытии.
- Исключение для ReVanced: `app.revanced.android.youtube` и `app.revanced.android.gms`.
- Распознавание сайтов YouTube и Instagram в поддерживаемых адресных полях Chrome, Samsung Internet, Firefox, Brave, Edge и Vivaldi.
- Запрос кода на распознанных страницах управления самим блокировщиком: сведения, удаление, хранилище и служба доступности.
- Поддержка раннего запуска Android Direct Boot.
- Минимальный экран входа, своя иконка часов, отсутствие рекламы и интернет-разрешения.

## Границы защиты

Это помощник для добровольного ограничения, а не неудаляемое системное приложение. Работа зависит от службы доступности и распознавания интерфейса. Отключение службы, безопасный режим, системные способы очистки/удаления, другие профили, клоны, встроенные браузеры и прокси могут позволять обход. После перезагрузки возможен промежуток до подключения службы. Ранний запуск не даёт гарантии непрерывной блокировки.

Не требуется root, прошивка или сброс телефона. Приложение не запрещает скачивание APK и не изменяет данные ReVanced.

## Приватность

Служба получает доступ к дереву окон, чтобы локально найти адресную строку браузера или имя блокировщика на странице управления. Адреса, страницы и введённый код не отправляются и не сохраняются в журналах. Проверка кода: индивидуальная соль и PBKDF2-HMAC-SHA256; открытый код не хранится. Резервное копирование данных приложения отключено.

## Сборка

Нужны JDK 17 или новее и Android SDK 36. Откройте проект в Android Studio или выполните:

```sh
./gradlew :app:assembleDebug
```

На Windows: `gradlew.bat :app:assembleDebug`.

Самостоятельная сборка подписывается локальным debug-ключом разработчика. Чтобы обновлять уже установленный APK без удаления данных, нужен тот же ключ подписи. Ключ распространённого APK в этом репозитории не опубликован. Поэтому собственная сборка может не установиться поверх APK из Releases.

APK можно скачивать и передавать знакомым. Перед передачей объясните первый запуск и отсутствие восстановления кода. Публичность исходников сама по себе не означает гарантии безопасности или лицензии на любые способы их использования.
